# 證據卡 05 — crow llm-wiki-v2

**節點權限：只看 raw/05-crow-llm-wiki-v2.md，不混入其他來源。**

可用的關鍵主張（數字要逐句照來源）：
1. ingest 時大多數 LLM 呼叫不是在「寫」而是在「決策」（歸哪個資料夾、是否同主題、要不要合併、連去哪），**佔約 72% 的 LLM token**。
2. 對策：決策交給小型 typed classifier，LLM 只負責文字。
3. 結果（525 份文件、單一語料單一模型）：正確筆記被送到答案的比例 62% → 89%，ingest 時間約減半，每份文件 token 成本在 wiki 變大時保持平坦。
4. 作者自註：單一語料、單一模型，只是第一個數據點（引用時要保留這個限制）。
5. 授權 AGPL-3.0、支援 Ollama 本地模型。
